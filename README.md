# Fargebroen- din fargerådgiver!🌈
Fargebroen er en app som tilbyr sertifisert fargerådgivning og boligplanlegging for deg som vil skape vakre, gjennomtenkte hjem - fra først fargevalg til ferdig resultat.
Hva vi tilbyr:
- Sertifisert fargerådgivning: Finn din perfekte fagepalett for hjemmet
- Boligplanlegging: helhetlig løsning fra start til slutt.
- Inspirasjon: Se hvordan farger endrer romfølelsen. 
## Ressurser og guider:📚
- Vi tilbyr skreddersydde PDF guider for deg som ønsker dypdykk i spesifikke fargetemaer eller planleggingsverktøy. 
- Komplette fargepaletter: Ferdig sammensatte paletter for ulike rom.
- Planleggingsverktøy: PDF-er som hjelper deg å holde styr på oppussingen.
Disse ressursene er tilgjengelige for en liten sum.
